### 2.6 已成型 JSON 约定

- 对外 JSON 字段使用 `snake_case`；Java 字段保持 `camelCase`，由 Jackson 全局策略转换；
- 业务主键为自增 `BIGINT`，Java/API 使用 `Long`，前端使用 `number`；
- 错误响应提供稳定错误码（如 `PROJECT_NOT_FOUND`、`KNOWLEDGE_INDEX_UNAVAILABLE`、`INSUFFICIENT_EVIDENCE`）和可读消息；
- 项目标识 `identifier` 在 URL 中需编码（如 `network%2Fdesigner`）。
