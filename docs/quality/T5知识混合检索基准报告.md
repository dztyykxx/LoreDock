## 7. 机器结果与复现

正式执行器生成 `backend/target/knowledge-search-benchmark-result.json`，包含 54 个实际执行项的完整返回文档 UUID/排名、匹配通路、相关性、警告、结果数、耗时、错误码，以及环境、generation、模型、逐模式汇总和门禁状态。`target` 是可再生构建产物，不提交仓库；使用下列命令可在目标 CPU 环境重新生成：

```bash
cd backend
JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home ./mvnw \
  -Dloredock.benchmark=true \
  -Dloredock.benchmark.model-dir=/path/to/bge-small-zh-v1.5 \
  -Dloredock.benchmark.output=target/knowledge-search-benchmark-result.json \
  -Dit.test=KnowledgeSearchBenchmarkIT \
  test-compile failsafe:integration-test failsafe:verify
```

执行器会先校验 15 份文档与 18 个问题均为人工审查的公开模拟材料，并扫描常见凭据、私钥、内部域名和私网地址模式。设置正式开关但模型缺失、资源摘要不符、查询异常、generation/模型/分块/融合配置变化或任何门禁未通过时，Maven 以失败退出，不用空结果或预设成功文字替代实际响应。
