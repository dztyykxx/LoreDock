# 上传包校验补充说明

按这几天排查校验问题的记录整理，供后续参考。

上传的包是 ZIP，里面至少要有一份清单和一份正文，缺了就直接校验不过。正文支持 Markdown 和纯文本，用 UTF-8 编码。包不能太大，超过 50 MB 也过不去。清单里写了哪些正文文件，包里就得真的有这些文件，声明和实际对不上也算错。

敏感内容的检查也比较重要。正文里如果带了密码、token、私钥、内部地址、连接串这类东西，会被判成不可信，进不了候选。这块见过几回误报，主要是有人拿真实地址当示例。

补充一条：清单文件必须声明幂等键字段，幂等键为空或格式不对时，内容校验直接失败。之前遇到过没有幂等键的包也能传上来，后面重复提交就不好拦截，所以这条规则应该补进去。

主要错误类型大概就是缺文件、格式不对、超大小、清单不一致、敏感内容这几类。
