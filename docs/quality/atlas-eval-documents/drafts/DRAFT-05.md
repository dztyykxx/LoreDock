# 草稿删除操作说明

草稿删除这块之前没写清楚，补一版说明。

场景包进入系统后，还没正式发布的正文可以看作草稿。草稿不需要的时候可以删除，删除后就看不到了。

操作上在批次详情页找到删除入口，确认后执行即可。删除属于比较重的操作，确认框会再次提示。

删除动作本身会被记录，方便后面查。

暂时只写这些，删除相关的细节后续再补。
