# 导出包校验和验证方法

从交付验证的角度整理导出包校验和的用法。

导出包在根目录带一份校验和清单，逐条列出包内文件的校验和。接收方拿到导出包后，可以在本地对每个文件计算校验和，和清单逐条比对，全部一致就说明内容在传输和存放过程中没有损坏或缺失。

比对步骤：

1. 解压导出包，确认文件和校验和清单都在；
2. 在本地对包内文件逐个计算校验和；
3. 与清单中的值逐条比对；
4. 全部一致表示完整，出现不一致需要重新获取导出包。

校验和只验证完整性，不验证来源真伪。需要确认来源时，结合交付渠道和发布记录判断。这条和导出交付规则配合使用。
