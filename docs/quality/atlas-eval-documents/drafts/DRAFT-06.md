# 大型场景包处理建议

场景包有大有小，比较大的场景包可能需要特殊处理。

大包包含的正文多、体积大，上传和校验都会比普通包慢，也更容易出现处理问题。建议在大包上传时特别注意打包内容，尽量控制包内文件的数量和体积。

如果大包在上传或校验过程中出现问题，可能需要分拆后再传。具体怎么分拆、分拆到什么程度合适，还没有定论，先记在这里，后面结合实际包再补充。

以上只是建议方向，不是硬性规则。
