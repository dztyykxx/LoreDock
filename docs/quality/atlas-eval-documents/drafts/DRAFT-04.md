# 场景包快速发布操作

记录一下低风险内容的快捷发布方式，提高交付效率。

有些场景包内容简单、风险低，比如格式说明、模板类材料。这类包上传后如果也走完整审核，比较耽误时间。实际操作中可以由上传成员在提交时勾选“低风险快速发布”，跳过等待审核的环节，直接成为正式知识。

具体步骤：

1. 上传场景包时在页面勾选快速发布；
2. 系统校验通过后不再进入待审核队列；
3. 直接发布为正式知识，立即可检索。

这样成员自己也能发布一些低风险材料，管理员只需要事后看审计记录。审核队列的积压也能减轻不少。

如果有需要走完整审核的包，不勾选即可，流程不变。
