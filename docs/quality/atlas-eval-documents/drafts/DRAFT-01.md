# 导入材料为什么需要审核

整理自一次评审会议的记录。

自动校验解决不了业务判断。格式问题和敏感内容能靠机器扫，但内容讲得对不对、关键信息全不全、和既有知识冲不冲突，机器看不出来。要是校验通过就直接变成正式知识，大家检索到错误内容就会当成事实用。所以发布前必须有人把关，由管理员确认过的内容才算数。

上传成功不等于发布成功。成员传完包，机器校验通过后也只是候选内容，要等管理员审核。管理员确认后才是正式知识，才能被检索到；确认之前一直处于候选状态，普通检索看不到。

发布入口只有管理员有。成员能上传、能看批次状态，但没有直接发布的入口，也绕不过审核这一步。

审核的时候主要看内容本身：业务说法对不对、关键信息全不全、跟既有知识有没有矛盾或重复、建议能不能执行、有没有敏感内容。审核不是走过场，发现问题就打回修改。

审核结果会留下记录并通知相关人员，方便事后核对。

大致就是这样，细节以平台上的实际界面为准。
