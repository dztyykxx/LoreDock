# 导入材料为什么需要审核

整理自一次评审会议的记录。

机器检查只能看出文件是不是齐、格式是不是对，看不出业务上说得对不对。如果机器直接放行，错误内容进到正式知识里，大家检索到就会当真。所以上传上来的东西都要先过一遍人，由管理员确认没问题才能对外。

正式知识不是上传了就自动有。成员传完包，系统校验通过之后只是候选，得等管理员审。管理员点头之后才是正式知识，才能被检索到。成员这边没有任何直接发布的入口，不能绕过这一层。

审不过的情况就退回改。管理员点拒绝，上传的人看原因改好再传。改完重新走一遍校验和审核，不会因为内容差不多的包就自动放行。

大致就是这样，细节以平台上的实际界面为准。
