# 发布完成后的通知模板

发布动作完成后会给相关人员发通知，这里整理通知模板和接收人范围。

通知标题：场景包已发布。

通知正文：

“您上传的场景包《{场景包标题}》已由管理员审核并正式发布。该内容现已进入正式知识，可以被检索和引用。如需调整，请联系管理员处理。”

接收人：

- 上传该场景包的成员；
- 该场景包所属项目的项目成员；
- 关注该主题的管理员。

通知只发一次，发布成功后触发。通知内容不包含正文明细和敏感数据，只保留状态和操作入口提示。

如果接收人不在项目范围内，不会收到这条通知。
