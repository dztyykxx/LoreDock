# V2 增量导入分支规则

## 适用范围

本文只适用于 `feature/scenario-package-v2`，不得用于判断 `main` 的能力。

## V2 能力

- 支持包版本 `2.0`；
- 单文件上限为 50 MiB；
- `mode=MERGE` 用于增量合并，`mode=REPLACE` 用于全量替换；
- `dryRun=true` 只执行解析、校验和影响分析，不写入数据、不创建刷新任务；
- 包内未出现的旧节点在 MERGE 模式下保持不变；
- 只有列入 `deletedNodeIds` 的节点才进入删除校验。

增量确认仍要求整批原子提交。任一新增连线引用缺失节点，整个导入失败，不能只保留通过的部分。
