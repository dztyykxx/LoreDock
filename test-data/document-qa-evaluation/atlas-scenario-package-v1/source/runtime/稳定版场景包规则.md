# 稳定版场景包规则

## 支持范围

当前稳定版只支持包版本 `1.3` 和全量替换模式。单个上传文件最大 20 MiB。稳定版不支持 `mode=MERGE`、`dryRun=true` 或 50 MiB 上限；这些仍是 V2 验证能力。

## 冲突处理

包内 `scenarioId` 已存在时，默认返回 `SCENARIO_ID_CONFLICT`。只有 `PROJECT_ADMIN` 在预检后显式选择全量替换，才能覆盖该场景。全量替换以包内完整场景定义为准，但不会修改项目成员和审批记录。

## 发布约束

导入事务成功不等于派生拓扑已经刷新完成。页面在刷新任务成功前应展示“场景已导入，拓扑处理中”。
