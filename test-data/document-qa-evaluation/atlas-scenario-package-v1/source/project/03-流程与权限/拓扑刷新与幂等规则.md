# 拓扑刷新与幂等规则

## 为什么导入后需要刷新拓扑

导入事务只保存场景、节点、连线和模板的业务事实。画布坐标投影、节点搜索摘要和场景预览图属于派生数据，因此在事务提交后由拓扑刷新任务重新计算。这样可以缩短导入事务，也能在派生计算失败时安全重试。

导入成功但画布暂时没有显示新节点时，应先查看拓扑刷新任务。任务处于 `PENDING` 或 `RUNNING` 时等待完成；任务为 `FAILED` 时由 `PROJECT_ADMIN` 重试刷新，不需要再次上传场景包。

## 幂等规则

客户端发起确认导入时必须提供 `requestId`。服务端在 24 小时内保存 `requestId` 与文件摘要：

- 相同 `requestId`、相同文件摘要：返回第一次导入结果，不重复写入或重复创建刷新任务；
- 相同 `requestId`、不同文件摘要：返回 `IMPORT_REQUEST_CONFLICT`；
- 超过 24 小时：该 `requestId` 不再承担幂等保证。
