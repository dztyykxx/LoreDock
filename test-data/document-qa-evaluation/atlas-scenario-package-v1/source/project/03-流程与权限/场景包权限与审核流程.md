# 场景包权限与审核流程

## 角色权限

- `VIEWER`：可以查看场景和下载已生成的导出文件，不能发起导入。
- `EDITOR`：可以上传场景包并执行导入预检，但不能确认覆盖已有场景。
- `PROJECT_ADMIN`：可以确认导入、允许全量替换、发起导出并查看项目审计记录。

## 导入流程

1. `EDITOR` 或 `PROJECT_ADMIN` 上传场景包并执行预检；
2. 系统展示新增、修改、替换和删除数量以及所有校验错误；
3. 涉及覆盖已有场景时，必须由 `PROJECT_ADMIN` 确认；
4. 确认后在一个事务中写入场景数据；
5. 事务提交后创建拓扑刷新任务；
6. 审计记录保存操作者、项目、包摘要、导入模式和结果，不保存敏感参数原值。

预检结果有效期为 30 分钟。文件内容变化或超过有效期后必须重新预检。
