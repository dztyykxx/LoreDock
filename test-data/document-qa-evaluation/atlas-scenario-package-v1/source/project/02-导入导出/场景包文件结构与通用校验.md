# 场景包文件结构与通用校验

## 文件结构

场景包使用 ZIP 容器，根目录必须包含：

- `manifest.json`：包版本、导出时间、来源项目和场景清单；
- `nodes.json`：节点及其业务参数；
- `edges.json`：连线和端点引用；
- `templates.json`：允许为空数组的参数模板清单。

根目录缺少 `manifest.json` 时返回 `PACKAGE_MANIFEST_MISSING`。ZIP 损坏、包含绝对路径或路径穿越条目时返回 `PACKAGE_ARCHIVE_INVALID`。

## 业务校验

系统先完成结构校验，再检查业务引用：

1. `scenarioId`、`nodeId` 和 `edgeId` 在各自范围内必须唯一；
2. 每条连线的起点和终点必须引用包内节点；
3. 节点引用的模板必须在 `templates.json` 中存在；
4. 包版本必须是当前分支声明支持的版本；
5. 包内不得出现密码、令牌或私钥字段。

任一校验失败时，整个场景包不写入正式数据，不允许只导入通过的场景。
