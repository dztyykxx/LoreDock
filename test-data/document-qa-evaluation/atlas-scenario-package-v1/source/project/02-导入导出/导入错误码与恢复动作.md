# 导入错误码与恢复动作

| 错误码 | 含义 | 建议动作 |
|---|---|---|
| `PACKAGE_MANIFEST_MISSING` | 根目录缺少 `manifest.json` | 补齐清单后重新打包 |
| `PACKAGE_ARCHIVE_INVALID` | ZIP 损坏或路径不安全 | 使用标准 ZIP 重新导出，不保留绝对路径 |
| `PACKAGE_VERSION_UNSUPPORTED` | 当前业务版本不支持包版本 | 使用当前稳定规则支持的版本重新导出 |
| `SCENARIO_ID_CONFLICT` | 导入模式不允许覆盖同标识场景 | 更换标识或显式选择允许的替换模式 |
| `NODE_REFERENCE_MISSING` | 连线或模板引用不存在 | 补齐被引用节点或模板 |
| `IMPORT_REQUEST_CONFLICT` | 同一幂等键对应了不同文件 | 更换幂等键后重新提交 |

校验错误不会创建正式场景，也不会触发拓扑刷新。系统故障发生在事务提交前时，整批回滚；发生在事务提交后、拓扑刷新阶段时，场景数据保留，刷新任务进入可重试状态。

用户重试前应先根据错误码区分“材料错误”和“系统故障”，不要通过反复上传同一个错误文件规避校验。
