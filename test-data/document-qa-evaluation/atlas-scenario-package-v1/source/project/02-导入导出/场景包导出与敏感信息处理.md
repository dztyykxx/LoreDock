# 场景包导出与敏感信息处理

## 导出内容

导出任务固定写入场景清单、节点、连线、参数模板和必要元数据。导出文件名格式为 `atlas-scenario-{scenarioId}-{yyyyMMddHHmm}.zip`。

导出不包含用户信息、审批记录正文、运行日志、密码、访问令牌、外部系统密钥和私钥。模板字段若被标记为敏感，只导出字段名称和“需要重新配置”的占位标记，不导出原值。

## 下载有效期

导出文件生成后可下载 24 小时。超过有效期后下载地址失效，用户需要重新发起导出任务。下载地址不得写入正式知识正文或聊天记录。

## 失败处理

导出失败不会改变场景数据。用户可以使用同一请求重新发起导出；系统不会复用失败任务产生的不完整文件。
