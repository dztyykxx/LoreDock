# REQ-2026-014 场景包增量导入需求

## 背景

大型场景包含数百个节点。全量替换会覆盖目标项目中的人工调整，演示团队希望只导入新增节点和明确修改的连线。

## 已确认需求

- 增量能力先作为 V2 方案验证，不改变当前稳定版的全量替换规则；
- 新包版本为 `2.0`，`manifest.json` 必须声明 `mode=MERGE` 或 `mode=REPLACE`；
- `MERGE` 模式只允许新增节点、更新显式列出的节点字段和新增连线；
- 删除节点必须在 `deletedNodeIds` 中明确声明，不能把“包内缺失”解释为删除；
- 支持 `dryRun=true` 只返回影响摘要，不写数据、不创建拓扑刷新任务；
- V2 验证环境上传上限调整为 50 MiB。

## 非目标

- 不在本需求中把增量能力正式发布；
- 不支持跨项目自动映射模板；
- 不通过完整代码快照推断变更结果。
