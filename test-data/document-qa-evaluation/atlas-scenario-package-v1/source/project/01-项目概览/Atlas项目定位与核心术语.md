# Atlas 项目定位与核心术语

## 项目定位

Atlas 是面向网络方案设计人员的场景编排平台。用户在画布中维护节点、连线和参数模板，并把一组可复用的设计内容保存为“场景包”。场景包用于跨项目复用经过审核的拓扑片段，不等同于完整项目备份。

## 核心术语

- **场景**：具有稳定 `scenarioId` 的业务设计单元。
- **场景包**：包含场景清单、节点、连线、参数模板和元数据的 ZIP 文件。
- **导入预检**：只解析和校验场景包，返回影响摘要，不写入正式设计数据。
- **拓扑刷新任务**：导入事务提交后异步重算画布投影和搜索摘要的后台任务。
- **全量替换**：以包内某个场景的完整定义覆盖目标项目中的同标识场景。
- **增量合并**：只合并包内声明的新增或修改项；该能力仅在演示分支验证。

## 不属于场景包的内容

场景包不包含用户密码、访问令牌、外部系统密钥、运行日志和项目成员信息。它也不是源代码归档，不能用于恢复服务端程序。
