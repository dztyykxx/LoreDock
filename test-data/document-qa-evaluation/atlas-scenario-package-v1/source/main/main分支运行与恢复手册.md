# main 分支运行与恢复手册

## 导入卡住

预检超过 2 分钟仍无结果时，可以取消本次预检并重新上传。确认导入后不能通过前端强制取消事务。

## 导入成功但画布未更新

先按 `requestId` 查询拓扑刷新任务：

- `PENDING` 或 `RUNNING`：等待，不要重复上传；
- `FAILED`：记录错误码，由 `PROJECT_ADMIN` 点击“重试刷新”；
- `SUCCEEDED` 但画布仍旧：刷新浏览器缓存，再核对所选项目和分支。

刷新重试只重算派生数据，不重复执行场景导入事务。连续三次刷新失败时，提交故障单并附上 `requestId`、项目标识和刷新错误码，不要附带场景包中的敏感参数。
