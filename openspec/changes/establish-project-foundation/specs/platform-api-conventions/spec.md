## Purpose

定义 LoreDock 后续 HTTP 能力共同遵守的错误、校验、时间、日志和审计契约，确保 Web、MCP 及后台操作能够获得一致、可追踪且不泄露敏感实现信息的基础语义。

## ADDED Requirements

### Requirement: HTTP API 必须返回统一错误响应
所有由应用处理的 HTTP API 错误 SHALL 返回统一 JSON 结构，至少包含稳定错误码、面向调用方的消息、UTC 时间戳和 trace ID。响应 MUST 使用与错误类别匹配的 HTTP 状态码，且不得返回堆栈、SQL、文件系统绝对路径、凭据或内部地址。

#### Scenario: 已知业务错误
- **WHEN** API 请求触发一个已定义的业务失败
- **THEN** 响应返回对应 HTTP 状态和稳定业务错误码，并包含可用于日志关联的 trace ID

#### Scenario: 未预期异常
- **WHEN** API 处理过程中发生未映射异常
- **THEN** 响应返回通用内部错误码和 HTTP 500，详细异常仅写入受控日志且响应中不泄露实现细节

### Requirement: 请求参数校验必须给出可定位的失败信息
HTTP 请求在进入业务处理前 MUST 校验结构、类型和声明的约束。校验失败 SHALL 返回 HTTP 400 和统一错误结构；字段错误明细 SHALL 标识字段路径和稳定原因码，不得回显密码、Token、密钥或不必要的原始正文。

#### Scenario: 多个字段不合法
- **WHEN** 请求同时包含多个违反已声明约束的字段
- **THEN** 响应一次返回全部可安全公开的字段错误，并且业务处理未执行

#### Scenario: 敏感字段不合法
- **WHEN** 密码、Token 或密钥类字段未通过校验
- **THEN** 响应可以指出字段及失败规则，但不包含该字段的原始值

### Requirement: 时间必须使用统一语义
系统持久化的业务时间 SHALL 以 UTC 语义保存，对外 JSON 时间 SHALL 使用包含 UTC 偏移的 ISO 8601 格式。领域和应用代码 MUST 通过可替换时钟获取当前时间，避免依赖服务器默认时区。

#### Scenario: 不同主机时区写入和读取
- **WHEN** 两个不同时区的运行环境处理同一 UTC 时刻
- **THEN** 持久化值表示同一瞬间，API 返回值包含明确偏移且不因主机默认时区改变

### Requirement: 可持久化业务记录必须遵循审计字段约定
需要审计的持久化业务记录 SHALL 具有创建时间、更新时间、创建者和更新者字段。应用在创建和修改记录时 MUST 自动维护这些字段；在认证能力尚未接入或由系统任务执行时，操作者 SHALL 记录为明确的系统身份，而不是伪造用户身份。

#### Scenario: 创建业务记录
- **WHEN** 应用创建一条采用审计约定的记录
- **THEN** 创建和更新时间被填充为当前 UTC 时刻，创建者和更新者被填充为当前操作者或系统身份

#### Scenario: 更新业务记录
- **WHEN** 应用修改一条既有记录
- **THEN** 原创建审计字段保持不变，更新时间和更新者反映本次修改

### Requirement: 日志必须可关联且保护敏感信息
应用日志 SHALL 包含时间、级别、服务、事件或消息及 trace ID 等关联信息。默认本地开发 profile SHALL 使用便于开发者阅读的文本控制台格式，不得把每条普通控制台日志强制编码为 JSON；生产 profile SHALL 使用机器可解析的结构化 JSON。对已知敏感字段、Authorization、数据库密码、模型密钥和对象正文 MUST 进行省略或脱敏；后台任务日志 SHALL 携带任务 ID。

#### Scenario: 本地开发查看控制台日志
- **WHEN** 开发者未启用生产 profile 而在宿主机启动后端
- **THEN** 控制台按可读文本格式展示时间、级别、线程、logger 和消息，不输出单行 Logstash JSON 对象

#### Scenario: 生产环境采集结构化日志
- **WHEN** 后端使用 `prod` profile 启动
- **THEN** 控制台输出机器可解析的结构化 JSON，并保留日志关联和脱敏约定

#### Scenario: 带 trace ID 的请求失败
- **WHEN** 一个 HTTP 请求处理失败
- **THEN** 错误响应中的 trace ID 可定位到对应服务端日志，日志不包含请求中的完整敏感值

#### Scenario: 后台任务失败
- **WHEN** 后台任务以失败结束
- **THEN** 相关日志包含任务 ID 和安全的错误上下文，不记录完整上传内容或凭据
