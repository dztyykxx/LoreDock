## MODIFIED Requirements

### Requirement: 工具执行必须由服务端白名单和固定范围授权
每个 Skill SHALL 只能看到并调用安全 Tool Registry 中由服务端结构化配置为当前任务授权的内部 Tool。执行器 MUST 在每次调用前校验工具名、操作者权限、运行固定的项目与默认分支、允许的知识范围、参数类型和服务端上限；模型、Skill、用户问题、会话历史或检索材料 MUST NOT 指定其他项目、服务器路径或扩大 Tool 权限。当前 `project_qa` 只允许知识搜索和指定文档的受限读取，不允许代码快照、PR/diff 或写入 Tool。

#### Scenario: 调用白名单内的知识 Tool
- **WHEN** `project_qa` 在固定项目内以合法参数调用声明的知识搜索或指定文档读取 Tool
- **THEN** 系统复用对应应用服务执行查询，记录有限 Tool 摘要，并只返回该运行范围内允许的已发布文档结果

#### Scenario: 模型尝试跨范围调用
- **WHEN** 模型 Tool 参数包含另一项目、历史索引 generation、服务器路径或超出上限的读取范围
- **THEN** Tool 在访问底层服务前拒绝调用，以 `AGENT_TOOL_SCOPE_VIOLATION` 终止运行，且响应和事件不暴露越权目标是否存在

#### Scenario: 模型请求白名单外工具
- **WHEN** 模型请求未在当前 Skill 白名单中的 Tool，或尝试访问代码快照、PR/diff、Shell、任意网络、数据库管理、知识修改或发布
- **THEN** 系统不执行该调用，以 `AGENT_TOOL_NOT_ALLOWED` 终止运行并记录 Tool 名称摘要和失败语义

#### Scenario: 会话或不可信材料包含操作指令
- **WHEN** 历史回答、知识、用户问题或 Skill 示例要求更改项目范围、泄露提示、调用外部网络或发布知识
- **THEN** 系统只把允许文本作为有限上下文或证据处理，结构化权限与 Tool 校验保持不变

## ADDED Requirements

### Requirement: 公开执行过程必须由真实事件和白名单载荷构成
Agent Runtime SHALL 把可公开执行过程投影为带运行 ID、单调序号、服务端时间、事件类别、主体类型和安全载荷的持久化事件。事件类别 SHALL 至少能够表达 Agent/模型阶段、Tool 开始与结束、来源发现、引用校验、可选公开决策摘要、公开文本增量和终态；主体类型 SHALL 能区分当前 Agent、模型、Tool 和服务端校验器，以便后续预定义子 Agent 复用同一信封。阶段、Tool 状态、来源和校验结果 MUST 来自服务端实际执行事实，不得由模型自然语言自述替代。

每类事件 MUST 使用字段白名单和长度/数量上限。Tool 输入输出只保存服务端生成的脱敏参数与结果摘要；来源只保存授权元数据；公开决策摘要必须标记为模型生成且不得改变工具或运行状态。完整系统提示、隐藏消息、模型原始思维链、原始 Tool JSON、完整证据正文、密钥、内部端点、对象键和服务器路径 MUST NOT 进入持久化事件、结构化日志或对外 API。

#### Scenario: Tool 调用形成公开事实链
- **WHEN** Agent 实际调用已授权知识搜索 Tool 并由服务端完成引用校验
- **THEN** 事件按序记录 Tool 开始、脱敏结果摘要、来源发现和校验结果，调用方可以证明发生了什么而不读取原始输入输出或隐藏推理

#### Scenario: 模型只声称调用工具
- **WHEN** 模型文本声称已经搜索或验证，但执行器没有收到和完成对应 Tool 调用
- **THEN** Runtime 不产生 Tool 完成或校验通过事件，该文本最多作为明确标记的公开决策摘要或普通文本处理

#### Scenario: 事件载荷超过安全上限
- **WHEN** Tool 查询、文档标题、来源列表、错误或模型公开摘要超过配置上限
- **THEN** Runtime 按稳定规则截断或裁剪并记录截断状态，不保存超限原文且不影响终态快照的业务真实性

#### Scenario: 运行失败后迟到事件
- **WHEN** 运行进入失败或终止状态后模型或 Tool 返回迟到的进度或结果
- **THEN** Runtime 不追加会使运行看似继续执行的公开业务事件、不改变终态，只保留既有脱敏诊断规则允许的忽略摘要
