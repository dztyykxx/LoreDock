## ADDED Requirements

### Requirement: 知识整理主 Agent 必须按需访问与应用用户记忆，专家不可见

系统 SHALL 在会话图顶层主 Agent（与用户对话、持有专家工具、决定下一步的调度角色）的入口上下文注入「用户记忆」摘要块：仅包含 `GLOBAL ∪ 当前会话项目` 的 `ACTIVE` 记忆，每条只含摘要（限长 300 码点），硬上限 30 条，全块限长 1800 码点。记忆摘要块 SHALL 在一个 run 首次主 Agent 上下文组装时生成并固定在该 run 上，同一 run 内后续组装（子图完成后回主 Agent 汇总、恢复重试）SHALL 复用同一快照，run 中工具读写（搜索摘要、加载全文、写入新记忆）MUST NOT 改变当前 run 的摘要块；快照只在下一 run 重新计算。记忆块与记忆工具 MUST NOT 出现在检索、草稿、审查专家与完整整理子图调度 Agent 的上下文中。主 Agent SHALL 通过记忆工具按需检索摘要、加载全文，并在起草、提问、汇总时应用符合当前任务上下文的偏好；记忆工具执行 SHALL 不扩大该 run 的项目、分支、知识范围、工具白名单或发布权限。

#### Scenario: 记忆只注入主 Agent

- **WHEN** 一轮会话执行，主 Agent 与专家依次获得上下文
- **THEN** 主 Agent 上下文中存在记忆摘要块，专家上下文不含记忆块、不含记忆工具

#### Scenario: run 内记忆前缀稳定

- **WHEN** 一个 run 的子图完成、主 Agent 再次组装上下文得到汇总指令，且该 run 中主 Agent 已调用过记忆工具（加载全文、写入过新记忆）
- **THEN** 汇总组装的记忆摘要块与首次组装逐字一致，run 中读写不影响快照；新写入记忆从下一 run 才可能进入摘要块

#### Scenario: 冲突偏好由模型按上下文择优

- **WHEN** 检索结果同时包含两条语义冲突的 `ACTIVE` 记忆（如正式用语与口语风格）
- **THEN** 主 Agent 依据本轮任务上下文与用户当前表述选择与任务匹配的一条执行，不得机械固定使用其中一条

#### Scenario: 草稿执行偏好经由主 Agent 指令传达

- **WHEN** 主 Agent 依据记忆决定草稿的格式、模板或内容取舍
- **THEN** 偏好以主 Agent 对专家的指令（任务说明）传达，专家指令中不出现记忆原文或记忆编号

### Requirement: 记忆工具按 run 范围约束且不扩大权限

`memory_search`、`memory_read`、`memory_write` 三个记忆工具 SHALL 只注册给会话图顶层主 Agent；工具 SHALL 在执行时按 run 校验运行存在、任务类型为知识整理、状态可执行、操作者/会话/项目一致；记忆工具结果 SHALL 被用作偏好上下文而不是事实证据。调用记忆工具 MUST NOT 扩大该 run 的项目、分支、知识范围、工具白名单或发布权限；记忆写入 MUST NOT 触发、恢复或变更知识整理任务本身。

#### Scenario: 记忆工具受限时拒绝执行

- **WHEN** 主 Agent 在 run 已结束或会话/项目与 run 不一致时调用记忆工具
- **THEN** 工具返回明确错误，不执行读取或写入

#### Scenario: 记忆不得引发任务变更

- **WHEN** 主 Agent 从记忆推断出新的整理目标或任务
- **THEN** 记忆只影响做事方式（格式、模板、风格、步骤序），任务目标与范围仍以触发目标为准，系统不得因记忆创建新任务
