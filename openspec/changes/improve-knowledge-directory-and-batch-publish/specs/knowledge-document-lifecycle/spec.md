## ADDED Requirements

### Requirement: 知识目录浏览必须使用稳定子树语义
系统 SHALL 把选中的非根目录解释为该目录自身及全部后代目录，并 SHALL 在服务端按当前通用或项目上下文、生命周期可见性和目录子树完成分页。目录树及每个节点的文档数量 MUST 基于当前上下文全部可见文档独立计算，不得由当前分页结果反推；管理员可见全部生命周期，普通成员只可见已发布文档。

#### Scenario: 管理员选择只有后代文档的父目录
- **WHEN** 管理员选择 `测试资料`，该目录自身没有文档但后代目录共有 18 篇文档
- **THEN** 页面保留当前上下文完整目录树，将 `测试资料` 显示为 18，并分页展示这 18 篇后代文档而不是空状态

#### Scenario: 普通成员选择父目录
- **WHEN** 普通成员选择一个同时包含已发布与草稿后代文档的父目录
- **THEN** 页面只统计并展示该子树内当前上下文允许的已发布文档，不泄露草稿、归档或其他项目数量

#### Scenario: 切换目录后旧详情越界
- **WHEN** 用户切换到不包含当前详情文档的目录
- **THEN** 页面清除旧详情和选择状态，不得同时显示空列表与范围外旧正文

### Requirement: 管理员可以显式批量发布本页草稿
系统 SHALL 允许管理员选择当前页的一至多篇草稿并调用批量发布接口。服务端 MUST 在一个事务中稳定锁定全部文档，按单篇发布的审计、修订和检索同步规则处理；任一文档不存在或已归档 MUST 使整批失败且不保存部分状态。已发布文档 SHALL 幂等返回而不改变首次发布时间、修订号或同步状态。批量发布 MUST NOT 建立替代关系、自动选择其他分页文档或自动提交重新索引。

#### Scenario: 批量发布导入草稿
- **WHEN** 管理员在当前页勾选 18 篇导入草稿并确认批量发布
- **THEN** 系统原子将 18 篇文档置为 `PUBLISHED`、记录同一操作者审计并标记为待索引，页面随后刷新真实目录和列表状态

#### Scenario: 批次包含归档文档
- **WHEN** 请求中的任一文档在提交前已经归档
- **THEN** 系统返回 HTTP 409 和 `DOCUMENT_STATE_CONFLICT`，该批次中的其他草稿仍保持草稿

#### Scenario: 重试已经成功的批次
- **WHEN** 管理员因响应不确定再次提交相同文档 ID，且这些文档已经发布
- **THEN** 系统幂等成功并明确返回已发布数量，不重复增加修订号或改变发布时间

#### Scenario: 普通成员绕过界面批量发布
- **WHEN** 普通成员直接调用批量发布接口
- **THEN** 系统返回 HTTP 403 和 `AUTH_FORBIDDEN`，所有文档状态保持不变
