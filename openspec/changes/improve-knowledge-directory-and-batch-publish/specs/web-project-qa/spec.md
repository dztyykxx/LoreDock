## ADDED Requirements

### Requirement: 项目页面必须提供一致的工作空间与问答导航
项目上下文页面 SHALL 把顶部“工作空间”呈现为返回项目列表的可键盘访问链接，并 SHALL 把公共侧栏中的“新建问答”和“问答”呈现为进入当前项目问答的真实链接。该问答继续使用服务端固定的当前项目默认分支范围，并可引用该范围允许的 `GLOBAL` 与当前项目已发布知识；导航 MUST NOT 创建独立全局问答范围或在没有项目时伪造项目选择。

#### Scenario: 从项目知识页返回项目列表
- **WHEN** 用户在项目知识页点击顶部“工作空间”
- **THEN** 前端导航到 `/projects`，不要求用户先点击左侧“项目”

#### Scenario: 从项目侧栏进入问答
- **WHEN** 用户在当前项目页面点击“问答”或“新建问答”
- **THEN** 前端进入 `/projects/{identifier}/qa`，其中“新建问答”打开无当前问题的新会话界面，问答仍可检索服务端允许的通用业务知识

#### Scenario: 非项目页面没有可锁定项目
- **WHEN** 用户在项目列表或通用知识页点击公共侧栏问答入口
- **THEN** 前端引导用户从项目列表选择问答范围，不伪造默认项目或发送无项目后端请求
