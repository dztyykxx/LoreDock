## MODIFIED Requirements

### Requirement: 问答详情和事件必须从已提交序号恢复且不重放运行
问答详情 SHALL 以持久化运行快照为事实来源，至少返回问答记录 ID、运行 ID、固定项目/分支/活动快照摘要、状态、结果类型、可信状态、拒答或错误码、最终公开正文、失败或终止时可空的脱敏 `failureMessage`、引用和最后事件序号。`failureMessage` MUST 由服务端根据稳定错误语义生成，不得包含模型异常原文、内部端点、服务器路径、隐藏提示或完整证据正文；新增该可空字段 SHALL 保持既有客户端兼容。

系统 SHALL 通过 `GET /api/projects/{identifier}/qa/questions/{questionId}/events` 提供 `text/event-stream`；每个业务事件 MUST 使用对应持久化 Agent 事件序号作为 SSE `id`，并提供稳定事件名、服务端时间和有限 JSON 数据。客户端 SHALL 能以标准 `Last-Event-ID` 或等价的非负 `afterSequence` 从已消费序号之后续读。服务端 MUST 先授权并验证项目与问答记录关联，再按严格递增顺序发送已提交事件；心跳不得占用业务序号。连接中断、页面刷新或同一序号重连 MUST NOT 重新执行模型、工具或创建新运行。运行进入终态后，SSE SHALL 发送终态事件并结束连接；客户端 MUST 再读取详情，以快照校正本地拼接状态和终态说明。

#### Scenario: 首次连接流式观察
- **WHEN** 客户端取得 HTTP 202 后先读取详情并从其已消费序号订阅 SSE
- **THEN** 页面按序看到运行阶段、有限工具/来源摘要、经校验文本增量和终态，且最终正文与详情快照一致

#### Scenario: 从已消费序号重连
- **WHEN** 浏览器已消费到序号 8 后连接中断并携带 `Last-Event-ID: 8` 重连
- **THEN** 服务端只发送序号大于 8 的已持久化事件，不重发更早业务事件、不重新调用模型，并最终与当前快照收敛

#### Scenario: 刷新恢复已完成拒答
- **WHEN** 用户刷新页面且关联运行已以 `REFUSAL` 完成
- **THEN** 页面从详情恢复拒答正文、稳定拒答原因、固定范围和候选来源，不创建新运行也不依赖刷新前内存

#### Scenario: 刷新恢复失败或终止说明
- **WHEN** 用户刷新页面且关联运行已失败或终止
- **THEN** 页面从详情恢复非空的脱敏 `failureMessage` 和稳定错误码，不创建助手消息、不展示未经校验的部分文本，也不依赖刷新前内存

#### Scenario: 活动流期间失去访问权
- **WHEN** Web 会话在活动流期间失效或当前操作者不再有项目读取权
- **THEN** 服务端停止继续公开业务事件；客户端显示需要重新登录或无法访问，且不把连接失败伪装成回答完成

### Requirement: 拒答和运行故障必须在回答区域提供可理解终态
拒答页面 SHALL 在回答主区域明确显示“当前知识库没有足够依据”、稳定拒答原因、实际项目与分支、当前快照状态及运行返回的少量当前范围候选来源，并提供记录知识缺口入口。分支没有活动快照且问题要求确认实现时 MUST 显示“当前分支代码尚未索引”，不得展示其他分支代码。拒答 SHALL 是 `COMPLETED/REFUSAL` 的正常公开结果，不得以通用“本次问答未完成”替代。

模型连接失败、限流、鉴权失败、运行队列繁忙、响应无效、步骤或模型调用达到上限、运行超时或中断时，当前问答 SHALL 在同一回答主区域显示与错误码稳定对应的脱敏 `failureMessage`、结果未被视为可信回答的说明以及可执行的下一步；内部错误码 MAY 作为次要诊断信息显示，但 MUST NOT 成为唯一或主要用户文案。重试 MUST 使用新的幂等键创建新运行。该故障 MUST NOT 改变应用 readiness，也不得阻止用户继续访问已发布文档、知识搜索和代码搜索。

失败或终止运行 MUST NOT 投影为可信 `ASSISTANT` 消息，MUST NOT 把工具摘要、模型中间文本或未通过引用校验的部分输出显示为最终回答。回答区域展示终态说明不改变运行的 `FAILED/TERMINATED` 事实，也不得将故障误标为 `INSUFFICIENT_EVIDENCE`。

#### Scenario: 当前分支没有快照但询问实现
- **WHEN** 用户询问具体实现而实际分支没有活动代码快照
- **THEN** 页面在回答区域显示“当前分支代码尚未索引”和“当前知识库没有足够依据”，可显示当前范围人工知识但不冒充代码事实

#### Scenario: 当前范围没有合格证据
- **WHEN** 运行以 `INSUFFICIENT_EVIDENCE` 或 `OUT_OF_SCOPE` 拒答完成
- **THEN** 页面把拒答正文作为本次正常结果显示，并提供稳定原因、有限相关来源和知识缺口入口，不使用模型常识补造项目事实

#### Scenario: 步骤上限终止
- **WHEN** 当前问答以 `AGENT_STEP_LIMIT_EXCEEDED` 终止
- **THEN** 页面在回答区域显示“本次检索已达到运行上限，尚未形成可信回答”等稳定脱敏说明，提示缩小问题范围或使用新运行重试，并把错误码降为次要诊断信息

#### Scenario: 模型暂时不可用
- **WHEN** 当前问答以 `AGENT_MODEL_UNAVAILABLE` 失败
- **THEN** 页面在回答区域显示模型暂时不可用及重新提问入口，同时文档浏览、知识搜索和代码搜索仍可正常调用

#### Scenario: 失败前存在中间模型文本
- **WHEN** 运行在工具或模型阶段产生过中间文本但随后失败或终止
- **THEN** 页面只显示服务端 `failureMessage` 和安全操作入口，不把中间文本标记或保存为可信最终回答
