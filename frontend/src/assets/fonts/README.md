# Geist 字体资产

本目录自托管 LoreDock UI 使用的 Geist 与 Geist Mono 可变字体，来源为 Vercel 官方 `geist-font` 的 `v1.7.2` 发布包。

- 发布包：`geist-font-v1.7.2.zip`
- 发布包 SHA-256：`7fc800d2ac6b92844895196e5041aca55d814c15db70c44f79b3b83ab82b04e2`
- 字体许可证：SIL Open Font License 1.1，见 `OFL.txt`
- `Geist-Variable.woff2`：官方 `Geist/webfonts/Geist[wght].woff2`
- `GeistMono-Variable.woff2`：官方 `GeistMono/webfonts/GeistMono[wght].woff2`

字体由 Vite 随前端静态资产一同构建，不从运行时外网加载。
